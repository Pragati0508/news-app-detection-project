# 🌐 Web Applications Collection

This repository contains two web applications developed using HTML, CSS, JavaScript, APIs, and AWS Cloud Services. These projects demonstrate frontend development, API integration, cloud computing concepts, and responsive web design.

---

# 📌 Projects Included

## ☁️ AWS Weather API Application

A serverless weather application that allows users to search for any city and retrieve real-time weather information through a custom AWS-hosted REST API.

### Features

- Search weather by city name
- Real-time weather information
- Responsive user interface
- Custom AWS API integration
- Error handling for invalid locations
- Dynamic weather updates

### Technologies Used

- HTML5
- CSS3
- JavaScript
- AWS Lambda
- Amazon API Gateway
- OpenWeather API

### Key Concepts

- REST API Development
- Serverless Computing
- Cloud Integration
- Asynchronous JavaScript
- JSON Data Handling

---

## 📰 News Search Application

A dynamic news application that fetches and displays the latest news articles based on user-entered keywords.

### Features

- Search news by keyword
- Real-time news updates
- News images and descriptions
- Direct links to complete articles
- Responsive card-based design
- Error handling for invalid requests

### Technologies Used

- HTML5
- CSS3
- JavaScript
- NewsAPI

### Key Concepts

- API Integration
- Fetch API
- DOM Manipulation
- Responsive Web Design
- Asynchronous Programming
